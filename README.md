# 概日リズム 体内時計 ガイド

起床時刻を入力するだけで、コルチゾール・メラトニン・体温のピーク時刻と、集中力・身体能力・睡眠の最適時間帯を推計して表示する個人向け体内時計ガイド。

## 機能
- 起床時刻 time input（LocalStorageで自動保存）
- 24時間カラーバンドタイムライン（色分けゾーン + 時刻マーカー）
- コルチゾール / メラトニン / 体温ピーク時刻をリアルタイム計算
- 各ゾーン（覚醒・集中・身体能力・就寝）の推奨アクティビティ表示
- 睡眠改善ヒント7項目（カフェイン・入浴・仮眠・光環境）

## 技術
- Vanilla JS + Tailwind CSS CDN
- localStorage（起床時刻の永続保存）
- 概日リズム研究ベースの相対時刻計算（起床時刻からのオフセット）
